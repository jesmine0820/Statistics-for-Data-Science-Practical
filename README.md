## 📚 Practical Exercises

This repository contains practical exercises for **BMMS2074 — Statistics for Data Science**, covering regression analysis, decision analysis, time series forecasting, and ARIMA modelling using R.

### 📈 Practical 1 — Simple Linear Regression
Introduction to simple linear regression and the relationship between two variables.

### 📊 Practical 2 — Multiple Linear Regression
Modelling the relationship between a dependent variable and multiple independent variables.

### 🎯 Practical 3 — Decision Analysis
Applying decision analysis techniques to evaluate alternatives and support decision-making.

### 📂 Practical 4 — Data Import & Preparation
- Uploading and importing data
- Creating time plots
- Splitting data into training and testing sets

### 📉 Practical 5 — Time Series Decomposition & Forecasting
- Linear models
- Time series decomposition
- Forecasting from STL
- Random walk models

### 🔮 Practical 6 — Exponential Smoothing & ETS Models
- Simple Exponential Smoothing (SES)
- Additive Holt-Winters Method
- Multiplicative Holt-Winters Method
- Holt-Winters Method
- Exponential Smoothing State Space (ETS) Model

### 📈 Practical 7 — ARIMA & Box-Jenkins
- ARIMA modelling
- Box-Jenkins procedure
- Automatic ARIMA (`auto.arima`)
